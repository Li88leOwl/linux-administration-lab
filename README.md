# 🐧 Linux Administration Lab

A hands-on Linux administration project focused on learning how to operate, troubleshoot, secure and recover Linux systems.

I’m approaching Linux from an infrastructure-engineering perspective.

The goal isn't to memorize commands.

The goal is to understand what the system is doing, why it is doing it, what can go wrong and how to recover when it does.

---

## 🎯 Goal

Become comfortable enough with Linux that I can:

* administer servers
* manage users and permissions
* understand processes and services
* configure networking
* troubleshoot connectivity
* manage storage
* work with logs
* configure SSH
* automate repetitive tasks
* secure a Linux server
* troubleshoot failures
* recover broken systems

## 🧠 Lab Rule

For every command:

```text
COMMAND
   ↓
WHAT DID IT RETURN?
   ↓
WHAT DOES THAT MEAN?
   ↓
WHY DOES IT MATTER?
   ↓
WHAT CAN GO WRONG?
   ↓
HOW WOULD I TROUBLESHOOT IT?
```
